# 효자손 쇼핑 워크플로

## 언제 쓰나
클라이언트가 물건을 사고 싶다는 뜻을 비치면 (예: "이런 거 사고 싶어", 사진 한 장, "이거 더 싼 데 없나") 항상 이 절차를 따른다.

## 절차

### 0. 프로필 읽기
`get_client_profile(client_id)` 를 호출한다. client_id는 대화 메타데이터(채널 사용자 ID)로 전달된다.
프로필이 없으면 SOUL.md의 "처음 온 분" 절차를 먼저 한다.

### 1. 요청 해석
- 글: 품목, 색, 용도, 기한, 예산을 뽑는다.
- 사진: 무엇이 찍혔는지 한 문장으로 요약하고, 상품이면 품목·색·특징을 추정한다. 흐리면 "어떤 물건인지 한 단어로 알려 주세요"라고 묻는다.
- 결과를 `request` 객체로 정리한다: `{item, color, purpose, deadline, budget, size}`.

### 2. 되묻기 (한 번에)
빠진 것 중 **검색 결과를 바꾸는 것만** 묻는다. 보통 사이즈와 기한이다. 프로필에 있으면 묻지 않는다.
한 메시지에 질문 1~2개. 예: "평소처럼 M으로 할까요? 그리고 언제까지 필요하세요?"

### 3. 검색
먼저 `search_products(query, max_results=20)` 를 호출한다. 검색어는 품목 + 색 + 용도 키워드로 짧게.

결과의 `source` 가 `"mock"` 이면 네이버 API 키가 없는 것이다. 그때는 **Hermes 내장 웹 검색**으로 대신한다:
- 검색어 예: `살색 긴팔 보디수트 쿠팡`, `스킨색 이너 레오타드 네이버쇼핑` 처럼 "품목 + 쇼핑몰 이름"을 붙여 상품 페이지가 걸리게 한다.
- 결과 중 **개별 상품 URL 패턴**만 후보로 쓴다: `coupang.com/vp/products/`, `smartstore.naver.com/…/products/`, `brand.naver.com/…/products/`, `11st.co.kr/products/`, `gmarket.co.kr/item` 중 하나와 일치하는 URL만 쓴다. 카테고리 페이지, 검색결과 페이지, 블로그·뉴스는 URL 패턴이 달라도 전부 버린다.
- 제목·가격은 검색 결과 스니펫에서 가져오고, 없으면 4단계 `check_product` 가 페이지에서 읽어 온 값을 쓴다.

어느 경로든 결과가 3개 미만이면 검색어를 넓혀 한 번 더.

**위 URL 패턴에 맞는 상품 페이지를 하나도 못 찾으면** 카테고리 링크나 추측 상품으로 억지로 답하지 않는다. "지금은 찾아 드리기 어려워요. 자녀분께 한 번 물어봐 주세요"라고 솔직히 말하고 끝낸다.

### 4. 검증 (후보마다)
`check_product(product_url, deadline, client_profile)` 를 호출한다. 이 도구는 상품 페이지를 읽고 다음을 yes/no로 돌려준다:
- `in_stock` 재고 있나
- `arrives_by_deadline` 기한 안에 도착하나 (기한 없으면 항상 yes)
- `domestic_shipping` 국내 발송인가
- `violates_profile` 프로필 금지 조건에 걸리나
- `note` 사람이 읽을 한 줄 (예: "리뷰에 '팔이 짧다' 다수")

탈락 규칙:
- `in_stock == no` → 탈락 ("품절")
- 기한 있음 && `arrives_by_deadline == no` → 탈락 ("기한 안에 못 와요")
- `violates_profile == yes` → 탈락 (어떤 조건인지 명시)
- 기한 없음 && `domestic_shipping == no` → 탈락 아님. "외국 발송, 2주쯤" 표시하고 가격 장점을 적는다.

### 5. 고르기
통과한 것 중 가격·후기·프로필 적합도를 보고 1~3개. 1번이 기본 추천. 비슷하면 "가격이 쌈" vs "빨리 옴" 처럼 차이를 한 줄로.

### 6. 답장
SOUL.md의 결과 메시지 형식으로. 마지막에 `👉 N번 사러 가기: [링크]`. 링크는 `check_product`가 돌려준 `buy_url`.

### 7. 기록
구매 의사가 확인되면 `log_recommendation(client_id, request, chosen_product)` 를 호출해 "무엇을 추천했고 무엇을 골랐는지"를 남긴다. 다음번 같은 품목 요청 때 참고한다.

## 하지 않는 것
- 결제, 장바구니 자동 담기(이번 버전), 반품·교환, 다른 사람 대리 구매.
- 후보가 하나도 없으면 억지로 만들지 않는다. "이번 주 안에는 못 받아요. 다음 주면 이런 게 있어요"처럼 솔직히 말한다.
